Ad Library Saver

Jev key

Your TypeSafe API key. It is stored in this Chrome profile only (chrome.storage.local, not synced) and is sent only to api.typesafe.ai.

Model

What leaves your computer

For each saved ad, Jev receives the advertiser name, the ad copy, the headline, the CTA button text and a media count (for example "1 video"). Nothing else: no images, no URLs, no browsing history. Ad Library content is public. Turn off "Tag new ads with Jev" in the popup to stop sending.
